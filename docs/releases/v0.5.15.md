# Agentao 0.5.15

This release is about a thinking model's reasoning: it now streams as the
model thinks, is kept whole in history, and is counted. `agentao run` takes a
thinking depth, and `agentao.log` times each request and shows its cache
counts. Four changes behave differently on upgrade; see
[Behaviour changes](#behaviour-changes).

## Behaviour changes

- **Validators move to new schema files.** `SubagentUsage` gains
  `reasoning_tokens`, and it is a closed model, so the field comes with new
  versions: replay schema **1.5** (`schemas/replay-event-1.5.json`) and the
  host event snapshot **`docs/schema/host.events.v2.json`**. The published
  files (`replay-event-1.0`–`1.4.json`, `host.events.v1.json`) are frozen as
  they were, so a validator built from one of them rejects the new field,
  which is always sent. Code that reads the models, or ignores unknown keys,
  needs no change. `agentao.replay.schema.build_event_schema()` now raises for
  a frozen version; read the published file instead.
- **`THINKING` arrives in pieces.** It used to be one event with the call's
  whole reasoning, after the stream ended. Each event is now one piece, in
  order, so a host that reads `THINKING` as one whole text (the legacy
  `thinking_callback` too) gets several calls per LLM call. A host client that
  replaces `LLMClient.chat_stream` must accept `on_reasoning_chunk=` (or
  `**kwargs`). A tool-call turn's text is no longer sent a second time as
  `THINKING`.
- **`agentao.log` lines are stamped `HH:MM:SS.mmm`.** A parser of the old
  `HH:MM:SS` prefix must allow the fraction.
- **`reasoning_content` is stored whole in history**, not cut to 500
  characters. Session files carry the whole text, and on `openai-completions`
  it goes back to the model whole.

## Reasoning

- **Reasoning streams as it arrives.** The CLI, ACP `agent_thought_chunk` and
  replay show it while the model thinks. Pieces are sanitized on the way out
  and join to exactly the `reasoning_content` that history keeps. Replay joins
  each stretch into one `assistant_thought_chunk` (at most 64,000 characters)
  before it scans for secrets, so a key split across two pieces is still
  redacted.
- **A final answer's reasoning is shown.** Before, only a tool-call turn
  emitted `THINKING`; an answer's reasoning reached `agentao.log` only.
- **Thinking backends get their chain of thought back whole.** DeepSeek, Kimi
  and similar backends on `openai-completions` used to get it back cut off
  mid-sentence inside their own tool loop.

## Observability

- **Each `LLM RESPONSE` block in `agentao.log` has `Duration: N ms`** (the
  attempt that produced it), **`Cache Read Tokens` and
  `Cache Creation Tokens`**. A failed attempt's error or retry line says
  `after N ms`. The developer guide has a `grep` recipe for requests that
  missed the cache.
- **Reasoning tokens are counted** as `reasoning_tokens`, a part of
  `completion_tokens`: on `LLM_CALL_COMPLETED`, in the log, in
  `agentao run`'s `usage`, in `SubagentUsage`, and in
  `LLMClient.total_reasoning_tokens` / `usage_snapshot()`. Chat Completions
  and `openai-responses` state it; on `anthropic-messages` it is always 0,
  because Anthropic counts thinking inside `output_tokens`.
- **`LLM_CALL_COMPLETED` gets `first_reasoning_ms`**, the wait for the first
  streamed reasoning piece. On a thinking model `first_token_ms` is the wait
  for the answer.

## Thinking depth

- **`agentao run` takes `thinking:` in the spec, or `--thinking LEVEL`.** It
  is the same setting as `/thinking`, written into the field the wire reads:
  `reasoning_effort`, `output_config.effort` or `reasoning.effort`. Before, a
  run could set it only through `LLM_EXTRA_BODY`, as `reasoning_effort`, which
  two of the three wires reject. `off` removes an explicit level so the
  provider's default applies. A level the wire refuses exits `2` before any
  request. The JSON result gains `thinking`.
- **A `/provider` switch to another wire moves the level `/thinking` set.**
  Before, the old wire's field stayed and every later request failed until
  `/thinking off`. A level the new wire does not take is dropped, with a log
  line. Only a level that agentao wrote moves: a field you set in
  `LLM_EXTRA_BODY` stays as it is.

## `agentao run`

- **The prompt is no longer sent twice on every request** (#549). A spec skill
  carried the whole prompt as its task, in the part of the request that is
  re-sent every time and never cached. A spec skill that fails to activate is
  now a `warnings` entry instead of being dropped silently.

## For hosts

New public names: `on_reasoning_chunk=` on `LLMClient.chat_stream`,
`LLMClient.total_reasoning_tokens`, `reasoning_tokens=` on
`LLMClient.add_usage`, `SubagentUsage.reasoning_tokens`, and in
`agentao.host.schema`: `FROZEN_SNAPSHOTS`, `HOST_EVENTS_SNAPSHOT` and
`snapshot_digest()`.

## Upgrading

```bash
pip install -U agentao
```

Check the four [behaviour changes](#behaviour-changes) above. See
`CHANGELOG.md` for the full list.
