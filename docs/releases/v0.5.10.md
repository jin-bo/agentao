# Agentao 0.5.10

This release adds three MCP features: OAuth login, resources, and skills. It
also rewrites the system prompt and the tool descriptions in Simplified
Technical English.

## MCP OAuth

A URL server (Streamable HTTP or SSE) now uses OAuth by default. No
configuration turns it on. When the server answers 401, `/mcp list` shows it
as `needs login`. agentao never opens a browser by itself:

```text
> /mcp login remote               # authorize in the browser
> /mcp login remote --no-browser  # print the URL, paste the redirect back (SSH)
> /mcp logout remote              # delete the stored credential
```

`agentao mcp login <name>` does the same from a shell. Use it for `agentao
run` and ACP sessions, which never start a login. Credentials are stored in
`~/.agentao/mcp-oauth/` (mode 0600, one file per server URL) and refresh
automatically. An optional `oauth` object in `mcp.json` takes `client_id`,
`client_secret`, `callback_port` and `redirect_host`. `"oauth": false`, a stdio
server, or an `Authorization` header turns OAuth off.

Limitations: on mcp 1.x the SDK does not check the authorization server's `iss`
(RFC 9207), and on mcp 1.26 each login registers a new client. A `403
insufficient_scope` is reported, but logging in again does not resolve it. A
server that needed login from startup loads its tools after a restart.

## MCP resources

When a connected server declares the `resources` capability, three read-only
tools are registered: `list_mcp_resources`, `list_mcp_resource_templates` and
`read_mcp_resource`. They are allowed in read-only and plan mode, and they
never ask for confirmation. `/mcp resources [server]` lists resources without
a model turn. `"resources": false` on a server hides it. A tool result's
`resource_link` now keeps its URI and names `read_mcp_resource`, instead of
the literal `[resource_link]`.

## MCP Skills

A server can publish Agent Skills through the `io.modelcontextprotocol/skills`
extension. It is off by default. Set `"skills": true` on the server. It needs
mcp 2.x and a server on protocol 2026-07-28 or later.

- Each skill is named `mcp:<server>:<SKILL.md URI>`. `activate_skill` asks the
  user once per skill per session, in every permission mode. agentao checks the
  skill's size, SHA-256 digest and frontmatter before the model sees it.
- `read_skill_file` reads the skill's other files, verified against its
  manifest.
- While an MCP skill is loaded, `run_shell_command`, a sub-agent that can run
  shell commands, and `read_mcp_resource` on another server ask first, until
  `/clear`. A `deny` rule still denies.

## Prompts and tool descriptions

- **The system prompt is rewritten in Simplified Technical English.** It has
  one list of when to ask the user, and approval rules that hold in every
  permission mode. An existing session's cached prompt prefix is rebuilt once.
- **Tool descriptions state what the code does.** Several said things the
  code does not do. For example, `read_file` promised all lines but returns at
  most 2000. `run_shell_command` said a background command is checked for
  errors, but it is not checked.

## For hosts

- **`AGENTS.md` is read when a project has no `AGENTAO.md`.** A cloned
  repository with an `AGENTS.md` now puts it in the system prompt. To read
  neither file, pass `Agentao(project_instructions="")`.
- **A URL server that answers 401 is now `needs_auth`** in
  `get_server_status()`, not a failed connect.
- **A transport with no confirmation callback now refuses MCP Skills
  confirmations.** `NullTransport`, an `SdkTransport` with no `confirm_tool`,
  and `build_compat_transport()` with no `confirmation_callback` still approve
  every other confirmation. A host that remembers "always allow" must read the
  new export `agentao.transport.gate_note()`. See `docs/reference/host-api.md`.
- **The `mcp:` skill-name prefix is reserved.** A local or plugin skill with
  that prefix is not loaded.
- **New:** `PathPolicy.contain_any()` in `agentao.security`, for a host
  `FileSystem` wrapper with several writable roots and read-only carve-outs.
  It is provisional and not part of the `agentao.host` contract.

## Upgrading

```bash
pip install -U agentao
```

No configuration changes are needed. MCP Skills needs `mcp>=2`. See
`CHANGELOG.md` for the full list.
