# Agentao 0.5.12

This release fixes image input across the CLI, ACP and every wire, and adds
host APIs: `Agentao.astream()`, `with` / `async with` / `aclose()`, and
`permission_mode=`. The CLI now shows a compaction while it runs. Four changes
behave differently on upgrade; see [Behaviour changes](#behaviour-changes).

## Behaviour changes

- **`close()` releases only the managers the agent built.** It used to
  disconnect an `mcp_manager=` and close a `memory_manager=` the host passed
  in. A host that relied on that now calls `disconnect_all()` / `close()` on
  its own manager. `build_from_environment()` hands its memory manager to the
  agent, so `close()` still releases that one.
- **`build_from_environment(replay_config=None)` turns replay off.** It used to
  read the `replay` block of `.agentao/settings.json` anyway. To keep reading
  the file, leave the argument out.
- **Only PNG, JPEG, GIF and WEBP images are accepted**, checked by their bytes.
  `/image` and ACP `session/prompt` refuse SVG, BMP, TIFF, HEIC and other
  types, and compressed data, before the request. ACP answers `-32602`. An
  image under a wrong label (`image/png` over JPEG bytes) is sent as the type
  its bytes show.
- **`add_event_observer` / `remove_event_observer` are deprecated.** They emit
  `DeprecationWarning`; use `add_host_event_observer` /
  `remove_host_event_observer`. They will be removed in a later minor release.

## Images

- **An image the provider refuses no longer breaks every later turn.** The
  image stayed in history, so every later request failed the same way, also
  after `/resume` or ACP `session/load`. Now a 400, 413 or 422 that mentions an
  image replaces the image parts in history with a note, and the turn ends
  asking you to re-attach the image, switch model or continue. A context
  overflow never removes images, and an error that only echoes your own text
  back ("describe this image") is not read as a refusal.
- **Switching to a text-only model after an image turn** no longer fails every
  later turn: images from earlier turns are replaced with a note and the
  request is retried.
- **An image URL the wire cannot send** (`anthropic-messages`: not `data:` or
  `http(s)`; `openai-responses`: empty) is sent as a text note instead of
  raising on every turn.
- **ACP image blocks accept `annotations` and `_meta`**, which the spec
  defines as optional. `docs/schema/host.acp.v1.json` now describes the
  optional prompt fields.
- `IMAGES_REMOVED` is a new event, recorded in replay; replay schema is now
  **1.4**.

## Compaction

- **The CLI shows compaction while it runs.** `/compact` shows a
  `Compacting context (12s)` spinner and the total time. A compaction inside a
  turn replaces `Thinking…` with the same spinner, then prints
  `Context compacted · 54 → 19 messages · 14s`.
- **`COMPACTION_STARTED` is a new event**, emitted just before the summarizer
  is called. Every start is followed by a `COMPACTION_SETTLED` unless the turn
  is cancelled. It is not recorded to replay.
- **Qwen parameter errors no longer trigger compaction.** DashScope's generic
  `InternalError.Algo.InvalidParameter` was read as a context overflow; its
  real overflow message is matched by its own wording.

## For hosts

- **`Agentao.astream()`** yields `TextDelta` items as the text streams, then
  the turn's `TurnOutcome`. Both are exported from `agentao.host`. Close it
  with `contextlib.aclosing` when leaving early.
- **`with Agentao(...) as agent:`, `async with`, and `aclose()`.** `aclose()`
  runs `close()` on its own thread, so the MCP disconnect does not block the
  event loop.
- **`Agentao(permission_mode="read-only" | "workspace-write" | "full-access")`**
  builds an engine in that mode without reading any permission file.
  `set_permission_mode()` accepts the string value too.
- **`CancellationToken`** is exported from `agentao.host`.
- **Every public `Agentao` method is annotated.** `transport=` is typed as the
  new `CoreTransport`. A strict type checker may report new errors on
  `compact(reason=)` and `agent.transport`; runtime behaviour is unchanged.
- **A `build_compat_transport(ask_user_callback=...)` callback that accepts the
  hint keywords now receives them.** A one-argument callback is unaffected, and
  a transport whose `ask_user` takes only the question works again.
- **A constructor that raises releases the MCP connections and memory stores
  it built.**
- **`close()` closes `agentao.log`**, so a temporary working directory can be
  deleted on Windows. New `LLMClient.close()` does the same for a client the
  host built.
- **Host events stay in order** when a full subscriber queue is drained while
  new events are published.

## Other fixes

- One bad entry or an unreadable `skills_registry.json` no longer erases every
  managed-skill record; concurrent installs keep each other's records.
- Replay listing, lookup and retention skip a file that cannot be read or was
  deleted while listing, and keep the valid records around a cut-off UTF-8
  character.
- A hook `timeout` out of the integer range is a warning, not a crash.
- A malformed `.agentao/goal.json` falls back to an empty goal.
- Search results keep U+0085, U+2028 and U+2029 inside matched lines.
- `/image` prints file names with brackets literally.

## Upgrading

```bash
pip install -U agentao
```

Check the four [behaviour changes](#behaviour-changes) above. See
`CHANGELOG.md` for the full list.
